N-step lookahead

Following the Kaggle N-step lookahead tutorial, the agent builds the game tree N plies deep (its move, the opponent's reply, …), scores every leaf with a heuristic, and backs the scores up with minimax: the agent picks the maximum, and assumes the opponent picks the minimum. A position where someone has already connected four is scored as ±109 (faster wins score higher), and a full board as 0, so all heuristics share the same terminal handling. Ties between equally good columns are broken at random.

Alpha-beta pruning

Alpha-beta keeps the best score the maximizer can already guarantee (α) and the best the minimizer can guarantee (β). As soon as α ≥ β the remaining siblings cannot change the decision and are skipped. The result is identical to plain minimax, but far fewer nodes are visited, especially when the strongest moves are searched first. Here that means trying the center columns first (3, 2, 4, 1, 5, 0, 6).
